Automatic Speech Recognition (ASR) Processing Architecture

01
🎙️
Audio Capture
Microphone captures analog sound waves, sampled at 16kHz or 44.1kHz into discrete PCM digital signals.
➔
02
📊
Acoustic Feature Extraction
Fast Fourier Transform (FFT) generates Mel-Frequency Cepstral Coefficients (MFCCs) or spectrogram vectors.
➔
03
🧠
Acoustic Model
Deep Neural Networks (CNNs/RNNs/Conformer) compute phoneme probability distributions from audio frames.
➔
04
📖
Language Model
Statistical N-gram or Transformer models score word sequence probabilities to disambiguate homophones.
➔
05
📝
Text Transcript
Beam search decoding outputs final punctuated and capitalized written text to the DOM.

1. Browser Web Speech API

The W3C Web Speech API provides a high-level JavaScript interface (SpeechRecognition / webkitSpeechRecognition) that interfaces the browser directly with native platform or cloud-assisted speech engines, streaming audio buffers asynchronously without server-side compute.

2. Interim vs. Final Results

During recognition, the engine fires onresult events with result.isFinal flags. Interim hypotheses are updated continuously as the speaker talks, allowing low-latency real-time display before finalizing with full contextual probability scoring.

3. Word Error Rate (WER)

ASR systems are mathematically evaluated using Word Error Rate: WER = (S + D + I) / N, where S is substitutions, D is deletions, I is insertions, and N is the total number of words in the ground truth reference.

4. Real-World Challenges

Ambient background noise, reverberation, dialectal variations, accents, co-articulation (slurring adjacent sounds), and homophones (e.g., “their” vs. “there”) represent the core engineering challenges solved by modern acoustic-linguistic models.

VoiceText Speech-to-Text Lab Guide

How to Use VoiceText:

  1. Click "Start Listening" or press the big glowing microphone button.
  2. Grant Microphone Permission when prompted by your browser (look for the camera/microphone icon in the URL bar).
  3. Speak clearly into your microphone. Words will appear in real time!
  4. Observe real-time statistics: Word count, characters, sentences, and duration update automatically.
  5. Click "Stop" to end capture, or use Copy Transcript to copy the recognized text.

Microphone Troubleshooting:

  • Ensure your browser has permission in Windows Settings: Settings > Privacy & Security > Microphone.
  • If speech recognition stops after a pause, keep Continuous Listening checked so it automatically maintains session state.
